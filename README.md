# Simple ETL Pipeline

This is a very basic ETL (Extract, Transform, Load) pipeline in Python using `pandas`.

## Files
- `etl_pipeline.py`: Main Python script
- `sample_data.csv`: Input data
- `output_data.csv`: Output after transformation

## What it does
1. Extracts data from a CSV file
2. Converts names to uppercase
3. Saves the cleaned data to a new CSV

## How to Run
Make sure Python and pandas are installed.

```bash
pip install pandas
python etl_pipeline.py
